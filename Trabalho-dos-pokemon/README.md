# 🐉 Projeto API Pokémon

Bem-vindo ao **Projeto Pokémon API**!  
Aqui você encontra informações de **TODOS os tipos de Pokémon**, com direito a consulta organizada e fácil de usar.  

---

## 🚀 Funcionalidades
- ✅ Listagem de todos os Pokémon disponíveis  
- ✅ Filtro por **tipos** (Fogo, Água, Planta, etc.)  
- ✅ Interface simples para testes  

---

## 🛠️ Tecnologias Utilizadas
 
- **PokéAPI** (dados oficiais dos Pokémon)  
- **JavaScript**
